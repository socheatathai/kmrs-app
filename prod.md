KMRS Production Deployment Guide
Architecture Overview
kmrs.tech              -> customer-web
merchant.kmrs.tech     -> merchant-cms
api.kmrs.tech          -> NestJS core-api
cdn.kmrs.tech          -> DigitalOcean Spaces CDN
1. Create GitHub Repository

Create repository:

kmrs-app

Push project:

git init
git add .
git commit -m "feat: initial project setup"

git remote add origin git@github.com:socheatathai/kmrs-app.git
git push -u origin main
2. Create DigitalOcean Server

Create Ubuntu droplet:

Recommended:

Ubuntu 24.04
Singapore region
2GB RAM minimum
3. Configure SSH
Generate SSH Key on Local Machine

Windows PowerShell:

ssh-keygen

Show public key:

cat ~/.ssh/id_ed25519.pub

Add key to:

GitHub SSH Keys
DigitalOcean SSH Keys
4. Connect to Server
ssh root@SERVER_IP
5. Generate SSH Key on Server
ssh-keygen -t ed25519 -C "server-kmrs"

Show key:

cat ~/.ssh/id_ed25519.pub

Add this server SSH key to GitHub.

Test:

ssh -T git@github.com
6. Clone Project
git clone git@github.com:socheatathai/kmrs-app.git
cd kmrs-app
7. Install Base Packages
apt update && apt upgrade -y
apt install git curl nginx -y
8. Install Node.js
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs

Check:

node -v
npm -v
9. Install pnpm
npm install -g pnpm
10. Install PostgreSQL
apt install postgresql postgresql-contrib -y
11. Create Database

Open PostgreSQL:

sudo -u postgres psql

Create database:

CREATE DATABASE kmrs_db;

Create user:

CREATE USER kmrs_user WITH ENCRYPTED PASSWORD 'YOUR_PASSWORD';

Grant DB access:

GRANT ALL PRIVILEGES ON DATABASE kmrs_db TO kmrs_user;

Connect database:

\c kmrs_db

Grant schema permissions:

GRANT USAGE, CREATE ON SCHEMA public TO kmrs_user;
GRANT ALL PRIVILEGES ON SCHEMA public TO kmrs_user;
ALTER SCHEMA public OWNER TO kmrs_user;

Exit:

\q
12. Add Swap Memory

Needed for small server RAM.

fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile

Permanent:

echo '/swapfile none swap sw 0 0' >> /etc/fstab

Check:

free -h
13. Install Project Dependencies
cd ~/kmrs-app
pnpm install --network-concurrency=1 --child-concurrency=1
14. Configure Environment Variables

Example:

vim ~/kmrs-app/apps/core-api/.env

Example .env:

DATABASE_URL="postgresql://kmrs_user:YOUR_PASSWORD@localhost:5432/kmrs_db?schema=public"

PORT=3333

JWT_SECRET="YOUR_SECRET"

PUBLIC_MENU_BASE_URL="https://kmrs.tech"

DO_SPACES_ENDPOINT="https://sgp1.digitaloceanspaces.com"
DO_SPACES_REGION="sgp1"
DO_SPACES_BUCKET="kmrs-cdn"

DO_SPACES_KEY="YOUR_KEY"
DO_SPACES_SECRET="YOUR_SECRET"

DO_SPACES_PUBLIC_URL="https://cdn.kmrs.tech"
15. Run Prisma Migration
cd ~/kmrs-app/apps/core-api

pnpm prisma migrate deploy
pnpm prisma generate
16. Build API
cd ~/kmrs-app

pnpm --filter core-api build
17. Install PM2
npm install -g pm2

Run API:

pm2 start "pnpm --filter core-api start" --name core-api

Check:

pm2 logs core-api
pm2 status

Save PM2:

pm2 save
pm2 startup

Run command generated by pm2 startup.

18. Configure Domains

DigitalOcean DNS:

Type	Hostname	Value
A	@	SERVER_IP
A	merchant	SERVER_IP
A	api	SERVER_IP
CNAME	cdn	kmrs-cdn.sgp1.cdn.digitaloceanspaces.com
19. Configure Nginx

Create config:

vim /etc/nginx/sites-available/kmrs-api

Config:

server {
    server_name api.kmrs.tech;

    location / {
        proxy_pass http://localhost:3333;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

Enable:

ln -s /etc/nginx/sites-available/kmrs-api /etc/nginx/sites-enabled/

Test:

nginx -t

Restart:

systemctl restart nginx
20. Configure SSL

Install Certbot:

apt install certbot python3-certbot-nginx -y

Generate SSL:

certbot --nginx -d api.kmrs.tech

Test:

curl https://api.kmrs.tech

22. Database Access Recommendation

Recommended:

Keep PostgreSQL private
Use SSH tunnel for local access

Example:

ssh -L 5432:localhost:5432 root@SERVER_IP

Then locally:

DATABASE_URL="postgresql://kmrs_user:PASSWORD@localhost:5432/kmrs_db?schema=public"
